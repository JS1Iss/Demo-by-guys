Rules
   EU: ===== GAME RULES =====
You are a team that is preparing the EKEB stand for the demonstration.
You have 6 moves and a maximum of 6 energy.

1. Inspect the stand — get the EKEB code, -1 move.
2. Take the charger — add it to your inventory, -1 move.
3. Use the charger — +3 energy, -1 move.
4. Fix the error — need 2 energy, -1 move.
5. Status — view energy, moves, and inventory.
6. Exit — end the game.

Goal: fix all errors before the moves end!

   RU:  ===== ПРАВИЛА ИГРЫ =====
Вы — команда, которая готовит стенд EKEB к демонстрации.
У вас есть 6 ходов и максимум 6 энергии.

1. Осмотреть стенд — получить код EKEB, -1 ход.
2. Забрать зарядку — добавить её в инвентарь, -1 ход.
3. Использовать зарядку — +3 энергии, -1 ход.
4. Исправить ошибку — нужно 2 энергии, -1 ход.
5. Статус — посмотреть энергию, ходы и инвентарь.
6. Выход — завершить игру.

Цель: исправить все ошибки до окончания ходов!
